# 삼국쟁투 튜토리얼 설계서 (v0.2)

- 날짜: 2026-11-11
- 상태: 대화에서 ①~④ 부분별 승인 완료, 이 문서 검토 대기
- 참고 자료: 진수 『삼국지』(정사) — 순욱은 191년 원소를 떠나 조조에게 귀부(「순욱전」)
- 로드맵 변경: 원래 v0.2였던 「전쟁이 계속 굴러가게」는 v0.3으로 밀림

## 1. 목표와 결정
처음 온 사람이 5~7분 안에 「내정 → 위임 → 출진 → 포위 → 공성 → 관전」을 한 번씩 직접 해 보고, 그 판을 그대로 이어 갈 수 있게 한다.

| 항목 | 결정 |
|---|---|
| 형태 | 실제 게임 화면 위 단계별 안내 + 고정된 연습 판 |
| 여는 때 | 처음 온 사람에게 한 번 묻기(예/아니요). 첫 화면 「튜토리얼」 버튼, 메뉴 「튜토리얼 다시 보기」 |
| 목소리 | 참모 순욱의 말투 + 말풍선마다 「▶ 할 일」 한 줄 |
| 목표 | 「허창을 차지하라」 |

## 2. 진행 순서
| # | id | 순욱의 말(요지) | ▶ 할 일 | 넘어가는 조건 |
|---|---|---|---|---|
| 1 | intro | 동탁이 천하를 어지럽히니 기반을 다져야 합니다. 남쪽 빈 성 허창을 손에 넣으시지요. | 「다음」 | 다음 |
| 2 | hud | 위에는 날짜와 금·식량·병력이, 지도에는 성마다 주인 색과 병력이 보입니다. | 「다음」 | 다음 |
| 3 | openCap | 근거지 진류를 살펴보시지요. | 진류 성을 누르세요 | 선택된 도시 = 진류 |
| 4 | stats | 인구가 많을수록 많이 뽑고, 민심이 낮으면 세금과 징병이 줄어듭니다. | 「다음」 | 다음 |
| 5 | recruit | 수도의 장수에게는 직접 일을 맡깁니다. 하후돈 장군에게 병사를 모으게 하시지요. | 하후돈의 할 일을 「징병」으로 | 하후돈.task = recruit |
| 6 | delegate | 다른 성은 태수에게 방침만 내리면 됩니다. | 복양 성을 누르세요 | 선택된 도시 = 복양 |
| 7 | endTurn1 | 한 달을 보내 보시지요. 할 일은 바꿀 때까지 계속됩니다. | 「턴 종료」 → 보고서 「확인」 | 턴 수가 1 늘고 보고서가 닫힘 |
| 8 | march | 출진입니다. 첫 부대가 총대장, 기병은 궁병에, 보병은 기병에 강합니다. | 진류 → 「출진」 → 목표 허창 → 「출진」 | 조조의 허창 포위가 있음 |
| 9 | siege | 성은 먼저 에워쌉니다. 에워쌀수록 성안의 식량과 사기가 떨어집니다. | 「턴 종료」 | 포위가 2턴째 이상 |
| 10 | assault | 포위 판에 「지금 치면 예상 승률」이 보입니다. | 포위 판 「공격」 → 「턴 종료」 | 허창 공성전이 일어남 |
| 11 | victory | 사다리와 성문, 기병 돌입. 승리를 축하드립니다! | 「결과 보기」 → 「확인」 | 허창 주인 = 조조 → 마무리 창 |

- 10단계: 예상 승률 90% 미만이면 「공격」을 권하지 않고 「한 턴 더 에워싸거나 공작을 쓰시지요」로 안내.
- 공성에서 지면 10단계로 돌아가 「다시 치시지요」.
- 포위가 풀리면(철수 등) 8단계로 돌아감.
- 마무리 창: 「이 판을 계속하기 / 새 게임 시작」.

## 3. 반드시 성공하게 하는 장치 (튜토리얼 동안만)
| 장치 | 규칙 |
|---|---|
| 고정 판 | `newTutorial()` = `newGame('cao', TUT_SEED)` + `G.tut = { step: 1, protect: true }` |
| 허창 보호 | `protect` 동안 AI의 공략 대상과 출진 목표에서 허창 제외 |
| 휴전 | `protect` 동안 AI의 공략 대상과 출진 목표에서 조조의 도시 제외 |
| 기본 편성 | 출진 창 기본값(장수 3명, 성 병력 60%)이 허창을 2턴 포위 뒤 95% 이상으로 이김 |
| 나머지 | 다른 세력끼리 싸움, 등용·사망·가상 인재는 평소대로 |
| 해제 | 허창 함락 또는 「건너뛰기」 즉시 `protect = false`. 이후 보통 판과 같음 |

보호는 **AI가 목표를 고르는 단계**(`aiPolicy`, `aiMilitary`)에서만 적용하고 전투 규칙은 건드리지 않는다. 보호 중에는 제목줄에 「연습 중(휴전)」을 표시한다.

## 4. 화면
- 말풍선: 휴대폰은 제목줄 아래, PC는 지도 왼쪽 아래. 포위 판은 말풍선이 있는 동안 그 아래로 비켜남
- 구성: 순욱 얼굴(16×16 코드 도트, 새로 그림) · 말 · 「▶ 할 일」 · 「3/11」 · 「다음」/「건너뛰기」
- 강조: 화면 요소는 금색 테두리 깜빡임, 지도 도시는 금색 고리
- 엉뚱한 곳을 누르면 막지 않고 말풍선을 흔들어 다시 안내. 단 「턴 종료」는 7·9·10단계에서만 눌림
- 새로 그리는 그림은 모두 코드 도트, 다른 작품의 그림을 따라 그리지 않음

## 5. 저장
| 칸 | 내용 |
|---|---|
| `gunung_save` | 본 게임(기존) |
| `samguk_tut` | 튜토리얼 판. 새로고침해도 같은 단계부터 |
| `samguk_seen` | 처음 왔는지 표시 |

- 저장 형식 `saveVer` 1 → 2. `migrate`는 형식 1에 `tut: null`을 넣는다
- 「이 판을 계속하기」: 튜토리얼 판을 본 칸으로 옮김. 본 칸에 판이 있으면 덮어쓸지 먼저 물음
- 「새 게임 시작」: 튜토리얼 칸을 지움

## 6. 인터페이스 (core.js, 화면과 무관)
- `newTutorial()` → G
- `TUT_STEPS` 단계 표: `{ id, say, todo, endTurn: bool }`
- `tutCheck(G, ev)` → 다음 단계로 갔으면 true. ev = `{ type: 'next'|'select'|'task'|'turn'|'siege'|'battle', ... }`
- `tutCanEndTurn(G)` → bool
- `tutSkip(G)`, `tutDone(G)` → 보호 해제
- 보호 판정: `isProtected(G, cityId)` — AI 목표 선택에서만 사용
