# 삼국쟁투 v0.3 「전쟁이 계속 굴러가게」 설계서

- 날짜: 2026-11-11
- 상태: 대화에서 ①~④ 부분별 승인 완료, 이 문서 검토 대기
- 참고 자료: 진수 『삼국지』(정사) — 190년 반동탁연합(관동 제후 연합)을 「연합」 규칙의 모티프로 삼음

## 1. 문제와 목표
AI끼리 10년 × 12판 진단(v0.2): 첫해 주인 바뀜 판당 약 7번, 4년차부터 AI 출진이 거의 0. 이웃끼리 병력이 비슷하게 불어나 「지금 공격력 ÷ 수비력」이 0.55~0.63에 머물고, AI의 출진 기준(0.85)을 넘지 못함.

| 결정 | 내용 |
|---|---|
| 후반의 느낌 | 통일 경쟁: 2~3강 구도, 너무 커진 세력은 연합이 견제 |
| 핵심 방법 | AI도 「준비하는 공성」으로 판단 + 후방 병력을 전선으로 모으는 「병력 수송」(플레이어도 사용) |
| 견제 | 자동 연합(40%에 생기고 30%에 해산) |
| 공성 곡선 | 수성 시설 수는 최대 성벽으로 고정, 위력은 성벽 비율에 연속으로 비례 |

## 2. 병력 수송
| 항목 | 규칙 |
|---|---|
| 명령 | `sendTroops(G, fromId, toId, n)`. 장수 없이 병사만 |
| 경로 | 아군 도시만 지나는 최단 경로(이웃 칸 단위). 경로가 없으면 보낼 수 없음 |
| 시간 | 한 칸에 1턴 |
| 비용 | 칸마다 n × 2% 식량을 보내는 도시가 출발 때 냄. 식량이 모자라면 못 보냄 |
| 제한 | 보내는 도시에 3,000 이상 남김, n ≥ 500, 포위당한 도시에서는 못 보냄 |
| 도중 | 다음 칸 도시나 목적지 주인이 바뀌면 지금 있는 칸에서 가장 가까운 아군 도시로 방향을 바꿈. 아군 도시가 하나도 없으면 흩어짐(사라짐) |
| 저장 | `G.convoys = [{ id, owner, path:[도시id...], at:칸 번호, troops }]` |
| 위임 방침 | `sup`(전선 지원): 3턴마다 이 도시의 「남는 병력」 절반을 가장 위험한 아군 전선 도시로 보냄 |
| 남는 병력 | 병력 − max(3,000, 이웃 적 최대 공격력 × 0.5에 맞먹는 병력). 적과 맞닿지 않은 도시는 3,000 |
| 가장 위험한 전선 | 이웃 적의 공격력 ÷ 우리 수비력이 가장 큰 아군 도시. 공략 방침 도시가 있으면 그곳 우선 |

AI 세력: 적과 맞닿지 않은 후방 도시는 자동으로 `sup`처럼 움직임. 플레이어의 위임 도시는 방침이 `sup`일 때만.

## 3. AI의 공략 판단
- **준비 뒤 기준**: 목표의 수비력을 「3턴 포위(사기 76) + 공작 2번(성벽 −2×(150+지력 70×3)=−720)」을 한 상태로 계산. 아군 출진 전력 ≥ 그 수비력 × `AI_ATK_GO`이면 출진. 공략 방침 선택(`aiPolicy`)도 같은 기준
- **한 번에 한 곳**: 세력마다 동시에 진행 중인 포위는 1개(플레이어는 제한 없음)
- **첫해 관망**: 191년에는 기준 × 2.2(시뮬레이션 조정, 처음 안은 1.3). 주인 없는 성은 예외
- **출진 병력**: 성 병력의 65%(시뮬레이션 조정, 처음 55%)
- **성 비우기 방지**: 기존 규칙 유지
- 포위 뒤 공격·공작·철수 판단은 기존 `aiSiegeOrder` 그대로

## 4. 연합
| 항목 | 규칙 |
|---|---|
| 확인 시점 | 매 턴 처리 시작(장수 일 배정 전) |
| 생김 | 한 세력이 전체 도시의 40% 이상(15개 중 6개+)이면 그 세력 = 패권. 둘 이상이면 도시가 많은 쪽, 같으면 병력이 많은 쪽 |
| 참가 | 패권 세력과 맞닿은 세력. 나중에 맞닿으면 그달부터 참가 |
| 연합끼리 | 서로를 공략 목표·출진 목표·수비 출격 대상에서 제외. 이미 하던 포위는 끝까지. 플레이어의 위임 도시(공략 방침)도 연합원은 치지 않음(저절로 탈퇴 방지) |
| 표적 우선 | 연합 AI는 목표를 고를 때 패권 세력 도시의 수비력을 ÷1.5로 보고 고름(판단 기준 자체는 그대로) |
| 해산 | 패권 세력 도시가 30% 미만(15개 중 4개 이하)이면 해산. 패권 세력이 멸망해도 해산 |
| 다시 짜기 | 연합 중에 다른 세력이 40% 이상이면서 표적보다 커지면, 연합을 풀고 그 세력을 표적으로 새로 짬(검토 반영) |
| 플레이어 | 패권이면 표적. 연합 쪽이면 연합 AI가 플레이어를 치지 않음. 플레이어가 연합 세력의 성을 출진 목표로 삼으면 플레이어만 탈퇴, 그 연합이 끝날 때까지 재가입 불가 |
| 튜토리얼 | `G.tut.protect` 동안 생기지 않음 |
| 저장 | `G.coalition = { target, members:[...], since:{year,month}, left:[...] } | null` |
| 표시 | 생김·해산은 큰 소식(보고서). 제목줄 「반○○ 연합」, 메뉴 세력 현황에 참가 표시, 지도에서 패권 세력 성에 붉은 테두리 |

## 5. 공성 곡선
- 시설 수 `towersFor(wallMax)` = ⌊최대 성벽 / 1000⌋, 최대 4(성마다 고정)
- 시설 위력 = `TOWER_DMG` × (0.2 + 0.8 × 성벽 / 최대 성벽)
- 성벽 방어 보정은 그대로(0.25 + 0.30 × 성벽 비율, 성문이 깨지면 절반)
- 포위 판: 「수성 시설 3 (위력 70%)」
- 기준값 `TOWER_DMG`는 시뮬레이션으로 정함

### 5-1. 조정 중 추가된 전투 규칙 (2026-11-11 사용자 승인: 그대로 유지)
「계단 없애기」와 「성문으로 쏟아져 들어가기」를 넣자 공성이 지나치게 쉬워져(준비 없이 81%) 아래를 함께 바꿨다.

| 규칙 | 예전 | 지금 | 하는 일 |
|---|---|---|---|
| 그날의 기세(`SWING`) | 없음 | ±25% | 전투마다 양쪽에 한 번씩 정하는 운. 접전일수록 결과가 갈림 |
| 성문 체력 | 성벽 × 0.4 | 350 + 성벽 × 0.6 | 성벽이 0이어도 성문은 버팀 |
| 수성 시설 기준값(`TOWER_DMG`) | 100 | 120 | 연속 위력으로 바꾼 만큼 보정 |
| 성문 통과 | 문 한 칸에 줄 섬 | 문 앞에 닿으면 곧장 성 안으로 | 문 앞 정체로 시간이 끝나는 일 방지 |

같은 조건 200판 비교: 지금 「준비 없이 22% · 포위 2턴 34% · 공작 2회 66%」, 셋을 예전 값으로 되돌리면 「81% · 97% · 100%」. 혼성군 피해 비중(35/35/30)과 보병끼리 공격 측 승률(51%)은 거의 같다.
