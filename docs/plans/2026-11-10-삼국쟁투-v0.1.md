# 삼국쟁투 v0.1 계획

- 목표: 191년 중원 15개 도시에서 30턴 땅따먹기가 돌아가는 첫 판
- 구조: `src/data.js`(표) + `src/core.js`(화면 없는 규칙) + `src/ui.js`(그리기·입력) → `build.py`가 `dist/index.html` 한 장으로 합침. 규칙을 화면과 떼어 Node에서 바로 시험한다.
- 도구: 외부 라이브러리 없음. 시험은 Node 내장 `node:test`, 브라우저 시험은 Playwright
- 설계서: `docs/specs/2026-11-10-삼국쟁투-설계.md`
- 실행 방식: 이 대화에서 직접(Native). 사용자 승인 「MVP 개발까지 추천 옵션으로 진행」

## 검토 초점(시험으로 막을 것)
1. 위임 AI와 적 AI가 다른 코드를 타는 일 → `tests/unit/core.test.js` 「같은 planCity」
2. 총대장 붕괴가 즉시 패배가 되는 일 → 「총대장 붕괴는 사기 −30」
3. 기병이 사다리를 타는 일 → 「기병은 성벽에 오르지 못함」
4. 옛 저장 불러오기 실패 → 「migrate」
5. 같은 seed에서 전투 결과가 달라지는 일 → 「전투 결정성」

## 작업
### 작업 1. 시험 틀과 핵심 규칙 시험(먼저 실패)
- 파일: `tests/load.js`, `tests/unit/core.test.js`
- 확인: `node --test tests/unit` → 실패(엔진 없음)

### 작업 2. 데이터 표와 엔진
- 파일: `src/data.js`, `src/core.js`

- 확인: `node --test tests/unit` → 전부 통과

### 작업 3. 화면과 빌드
- 파일: `src/shell.html`, `src/style.css`, `src/ui.js`, `build.py`
