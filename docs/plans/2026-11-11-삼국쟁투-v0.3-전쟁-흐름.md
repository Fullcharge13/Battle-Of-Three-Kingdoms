# 삼국쟁투 v0.3 「전쟁이 계속 굴러가게」 구현 계획

> 실행 방식은 사용자가 고른다(아래). 단계는 체크박스로 추적한다.

**목표:** AI가 후반에도 준비된 공성과 병력 수송으로 전쟁을 이어 가고, 너무 커진 세력은 연합이 견제하게 한다.

**구조:** 규칙은 모두 `src/core.js`(화면 무관, Node에서 시험). 새 상태는 `G.convoys`, `G.coalition`. 화면은 `src/ui.js`가 명령 창·표시만 담당. 밸런스는 `tests/sim/balance.js`로 잼.

**기술:** 외부 라이브러리 없음. Node `node:test`, Playwright(Python).

**설계서:** `docs/specs/2026-11-11-전쟁-흐름-설계.md`

## 전체 조건
- `saveVer` = 3. `migrate`가 형식 2에 `convoys: []`, `coalition: null`을 넣음
- 게임 안 버전 표시 `v0.3`, README·LOG와 맞춤
- 튜토리얼 보호(`isProtected`)는 새 AI 경로(수송·연합·공략)에서도 지켜야 함
- 커밋·푸시·공개판 반영은 마무리에서 허락 후

## 검토 초점
1. 수송 행렬이 포위·함락·멸망과 겹칠 때 병력이 두 번 세어지거나 사라짐 → 작업 2 「병력 보존」
2. 연합이 40%·30% 경계에서 매달 생겼다 풀렸다 함 → 작업 4 「경계 흔들림 없음」
3. 새 AI가 튜토리얼 보호를 뚫음 → 작업 3·4 시험에서 `newTutorial` 판 24턴
4. 플레이어가 연합 쪽일 때 AI가 플레이어를 치는 일 → 작업 4 「연합 AI는 플레이어 비공격」
5. 옛 저장(형식 2)에 convoys·coalition 없음 → 작업 2 「옛 판 옮기기」

### 작업 2: 병력 수송
**파일:** `src/core.js` / 시험 `tests/unit/war.test.js`(새로 만듦)
- 인터페이스: `ownPath(G, fromId, toId): string[] | null`(아군 도시만, 양 끝 포함), `sendTroops(G, fromId, toId, n): convoy | null`, `tickConvoys(G)`(endTurn에서 경제 전에 호출), `spareTroops(G, cityId): number`
- [ ] 시험(실패 확인):
  - 이웃 도시로 5000 → 다음 `endTurn` 뒤 도착(목적지 병력 +5000), 두 칸이면 2턴
  - 출발 때 식량 = 칸 수 × 5000 × 0.02 감소
  - 남김 3000 미만이면 null, n < 500이면 null, 포위당한 도시면 null, 경로 없으면 null
  - 「병력 보존」: 다음 칸이 적에게 넘어가면 가까운 아군 도시로 가서 병력 그대로 합쳐짐(전체 병력 합 = 보낸 병력)
  - 아군 도시가 없어지면 행렬 사라짐
  - 저장·불러오기 뒤 행렬 그대로, 「옛 판 옮기기」 형식 2 → 3
- [ ] 구현(경로는 너비 우선 탐색)
- [ ] 통과 확인
