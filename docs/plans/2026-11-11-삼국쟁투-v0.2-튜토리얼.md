# 삼국쟁투 v0.2 튜토리얼 구현 계획

> 실행 방식은 사용자가 고른다(아래 「실행 방식」). 단계는 체크박스로 추적한다.

**목표:** 처음 온 사람이 고정된 연습 판에서 순욱의 안내를 따라 11단계를 해 보고 허창을 함락한 뒤 그 판을 이어 갈 수 있게 한다.

**구조:** 단계 표·단계 판정·보호 규칙은 화면과 무관하게 `src/core.js`에 두어 Node에서 시험한다. 말풍선·강조·저장 칸은 `src/ui.js`가 맡고 core의 `tutCheck`에 사건을 넘기기만 한다. 보호는 AI가 목표를 고르는 두 함수에서만 적용한다.

**기술:** 외부 라이브러리 없음. Node `node:test`, Playwright(Python).

**설계서:** `docs/specs/2026-11-11-튜토리얼-설계.md`

## 전체 조건
- 저장 형식 `saveVer` = 2. 형식 1은 `migrate`가 `tut: null`로 옮김
- 저장 칸: 본 게임 `gunung_save`(그대로), 튜토리얼 `samguk_tut`, 첫 방문 `samguk_seen`
- 게임 안 버전 표시 `v0.2`, README·LOG 판 번호 v0.2와 맞춤
- 새 그림은 코드 도트만. 참고 자료 표기는 정사·연의만
- 커밋·푸시·공개판(`gh-pages`) 반영은 마무리에서 사용자 허락 후

## 검토 초점 (시험이 놓치기 쉬운 것)
1. 튜토리얼 판의 `protect`가 일반 새 게임에 새는 것 → 작업 1 「일반 판에는 보호 없음」
2. 플레이어가 출진 병력을 줄였거나 철수해 포위가 사라짐 → 작업 2 「포위가 없어지면 8단계로」
3. 튜토리얼 중 다른 세력이 허창 아닌 길로 조조 수도를 위협 → 작업 1 「보호 24턴」이 조조 도시 전체를 확인
4. 새로고침 뒤 단계가 1로 돌아감 → 작업 4 「튜토리얼 칸 저장·불러오기」
5. 휴대폰에서 말풍선이 도시 창·포위 판을 가림 → 작업 5 브라우저 시험의 가림 검사

## 실행 방식
- **이 대화에서 직접(Native)**: 작업 1~5를 차례로 하고, 끝에 새 검토자 한 명이 전체를 봄. 빠르고 저렴함
- **작업마다 새 일꾼(Subagent-driven)**: 작업마다 새 일꾼이 구현하고 다른 검토자가 확인. 가장 꼼꼼하지만 느리고 비쌈
